#### ¿Qué es un Active Directory?

* Almacena información acerca de los recursos de una red y facilita su organización y gestión por parte de los usuarios y administradores.
* Utiliza un almacén de datos estructurado como base para una organización jerárquica de la información. Este almacén se denomina directorio.

Los recursos almacenados en Active Directory suelen incluir:
* Servidores, impresoras, cuentas de usuario, equipo de red.

Servicios disponibles dentro de Active Directory:
* Autenticación, Autorización (se encarga de asegurar un acceso a datos y servicios que tiene permitidos cada usuario), Resolución de nombres, Gestión centralizada.
